# Code of Conduct

Forge Layer is a public record, not a club. Contributors and users are expected to:

- Argue about the protocol, not the person.
- Keep examples in issues and PRs free of personal data.
- Never paste private keys, seed phrases, or production `XAI_API_KEY` values.
- Mark security issues as private (see `SECURITY.md`).

Harassment, doxxing, or using the registry to store illegal content will get you banned from the project spaces. Maintainers may close issues that ignore this.

This is adapted from the spirit of the Contributor Covenant, kept short on purpose.
